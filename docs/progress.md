# 進捗ログ

- 初期スケルトン作成: ディレクトリ構成、データクラス、SUUMO パーサーの雛形、CSV 出力のエントリーポイントを追加。
- SUUMO の実際のカセット形式に合わせてパーサーのセレクタとロジックを更新し、room ごとの行も安全に処理するよう改善。
- `SUUMO_HTML_FILE` でローカル HTML を読み込めるようにして、オフラインでも挙動確認できるサンプル (`data/sample_suumo.html`) を用意。
- 外部ネットワーク（PyPI/SUUMO へのアクセス）がプロキシにより 403 で遮断され、実際のページ取得と依存ライブラリのインストールは未実施。オンライン環境で再確認する。
- 実行手順書 `docs/runbook.md` を追加し、仮想環境構築、サンプル HTML でのオフライン実行、本番取得手順、トラブルシュートを整理。pip での依存インストールは引き続きプロキシ 403 で失敗。
- `Makefile` を追加し、`make install` / `make run-sample` / `make run` でセットアップと実行を一括化。プロキシ環境でも最小コマンドで試せるようにした。
